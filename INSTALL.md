# Установка

```bash
pip install -r requirements.txt
apt-get install -y tesseract-ocr tesseract-ocr-rus     # см. ниже
```

## Про tesseract

Шесть страниц в архиве — изображения без текстового слоя, и на них лежат
несущие таблицы. Без распознавания конвейер не падает: он пишет
предупреждение и работает по остальным документам, но три ловушки при этом
открываются заново, а вердикт выглядит обоснованным.

Языковой пакет определяется автоматически:

| Установлено | Что читается | Последствие |
|---|---|---|
| `tesseract-ocr` + `tesseract-ocr-rus` | страница целиком | полное покрытие |
| только `tesseract-ocr` | латиница и цифры | таблицы разбираются, заголовки нет |
| нет tesseract | ничего | предупреждение в логе, сканы пропущены |

Средний режим работоспособен потому, что парсеры таблиц опираются на
структуру строки, а не на слова: строка данных заканчивается процентом,
формулировка правила содержит процент в середине предложения.
